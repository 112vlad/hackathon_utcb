# 🚲 VeloCivic Cycling Infrastructure Platform

Full-stack civic platform for **cycling infrastructure reporting and management in Bucharest’s Sector 2**, built in **48 hours**.

## 🚀 Features

* **Dual-interface web app** with dedicated citizen and admin dashboards
* **A* bidirectional routing** on a custom PostgreSQL road graph with safety-weighted edge costs
* **VeloScore** — composite metric for cycling infrastructure simulation
* **GTFS public transport data** integration
* **OpenStreetMap** layers with Leaflet
* **Docker Compose** deployment

## 🛠️ Tech Stack

* **Backend:** Node.js, TypeScript
* **Frontend:** Next.js, React 19
* **Database:** PostgreSQL
* **Routing:** Bidirectional A*
* **Maps:** Leaflet, OpenStreetMap
* **Data:** GTFS
* **Deployment:** Docker Compose
